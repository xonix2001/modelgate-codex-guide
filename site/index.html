二、准备环境：Codex + CC Switch

安装 CC Switch

根据你的电脑系统下载安装包，下载完成后按提示安装。

  • macOS 安装包从 Releases 获取当前版本
  • Windows 安装包从 Releases 获取当前版本

三、接入操作

兑换额度

注册并登录 Sub2API 后，点击左侧菜单中的“兑换”，输入购买的兑换码完成兑换。

创建并导入 API 密钥

创建密钥，选择对应的号池，然后点击“导入到 CCS”。

使用密钥

密钥创建完成后，点击“使用密钥”，进入配置页面。

启用配置并重启 Codex

进入 CC Switch 页面后点击“启用”。随后请彻底退出 Codex：Windows 用户通过任务管理器退出，macOS 用户在菜单栏右击并彻底退出。重新打开 Codex 后即可使用。

最后一步：仅关闭窗口可能不会结束 Codex 进程，请确认它已彻底退出后再重新打开。
