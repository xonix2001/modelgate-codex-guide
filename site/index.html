Full Guide

从零完成 Codex 接入

教程完整保留。按顺序操作，最后务必彻底退出并重新打开 Codex。

下载 Codex ↗下载 CC Switch ↗购买兑换码 ↗

兑换额度

注册并登录后，打开“兑换”页面，输入购买的兑换码完成兑换。

创建并导入 API 密钥

创建密钥，选择对应号池，然后点击“导入到 CCS”。

使用密钥

密钥创建完成后，点击“使用密钥”，进入客户端配置页面。

启用配置并重启 Codex

在 CC Switch 页面点击“启用”，随后彻底退出并重新打开 Codex。

关键一步：仅关闭窗口可能不会结束进程。Windows 请在任务管理器中确认退出；macOS 请从菜单栏彻底退出。

准备好开始了吗？

进入控制台注册账号，或先查看兑换码选项。实际调用可能产生费用，请在使用前核对当前计费与服务条款。
